System Architecture

Factory Inventory Management System

A three-tier demo application. A Vue 3 single-page app talks to a FastAPI service over HTTP/JSON; the service reads seven JSON files into memory at startup. There is no database and nothing persists — restarting the server reloads the original data.

Architecture

Each tier runs as its own process. The browser holds all UI state; the server holds all data and does all filtering.

Data flow

One shared filter bar drives every page. Changing a filter triggers this eight-step round trip.

  1. User changes a filter. Four dropdowns: time period, location, category, order status.
    components/FilterBar.vue
  2. Shared state updates. The four refs live at module scope, so every importer sees one instance — a singleton store without a store library.
    composables/useFilters.js
  3. Views react. Each view watches all four refs and re-runs its loader.
    views/*.vue — watch([...], loadData)
  4. Request is built. getCurrentFilters() returns a plain object; the API client turns it into URLSearchParams and drops any value equal to 'all'.
    api.js → GET http://localhost:8001/api/…
  5. Server filters in memory. apply_filters() chains list comprehensions over warehouse, category and status; filter_by_month() matches a YYYY-MM prefix or expands a quarter key via QUARTER_MAP. Originals are never mutated.
    server/main.py
  6. Pydantic validates the response. response_model enforces the shape and drops unexpected fields before serialization.
    server/main.py — model classes
  7. Raw arrays land in refs. Views store exactly what the API returned — allOrders, inventoryItems, summary.
    views/Dashboard.vue and peers
  8. Computed properties derive everything else. KPI tiles, category bars, order trends and top products are all computed — no duplicated derived state. Dashboard.vue alone defines 12.
    Template re-renders

Filter dimensions

Values in the data

  • Warehouses: San Francisco, London, Tokyo
  • Categories: Circuit Boards, Sensors, Actuators, Controllers, Power Supplies
  • Order statuses: Delivered, Shipped, Processing, Backordered
  • Date range: 2025-01-02 to 2025-12-31

Matching rules

  • 'all' is the skip sentinel — the client never sends it and the server ignores it.
  • Warehouse matching is exact and case-sensitive.
  • Category and status matching is case-insensitive; the client sends lowercase.
  • Month accepts 2025-03 or a quarter key such as Q1-2025, matched as a substring of order_date.

Cross-cutting concerns

Internationalization

A hand-rolled i18n layer, not vue-i18n. useI18n.js walks a dotted key path through locales/en.js or ja.js, falls back to English, then to the raw key.

  • Locale persists in localStorage under app-locale.
  • Currency follows locale: en→USD, ja→JPY.
  • Dedicated helpers translate product, customer and warehouse names in the data itself.

Auth and money

  • useAuth.js hardcodes isAuthenticated = true and one mock user; logout shows an alert.
  • User profile fields and task list swap language inside a computed keyed on locale.
  • utils/currency.js converts with a fixed USD→JPY rate of 150 — display only, no live rates.
  • Revenue goals are business constants: $800K per month, $9.6M year-to-date.

Gaps found while reading the code

Facts, not recommendations. Each was confirmed against the source in this checkout.

Client calls endpoints the server does not define

  • api.js exposes six methods against /api/tasks and /api/purchase-orders. main.py declares neither, so every one of those requests returns 404.
  • App.vue calls api.getTasks() in onMounted. The failure is caught and logged to the console, and the UI falls back to the four mock tasks in useAuth.js — so the break is invisible in the browser.
  • The PurchaseOrder and CreatePurchaseOrderRequest models exist in main.py but no route references them.
  • /api/backlog sets has_purchase_order by scanning purchase_orders.json, which is empty — the flag is always false.

Dead and inconsistent code paths

  • views/Backlog.vue (152 lines) has no route in main.js and is imported nowhere. Backlog UI is duplicated inline in Dashboard.vue.
  • Reports.vue is the only view that skips api.js, calling axios.get('http://localhost:8001/api/reports/...') with the host hardcoded twice.
  • get_quarterly_reports() re-derives quarters with a chain of if/elif string checks instead of reusing the QUARTER_MAP defined 220 lines above it.

Demo-only posture

  • No authentication or authorization on any endpoint.
  • CORS permits all origins, methods and headers.
  • No rate limiting, pagination or request size limits. All 250 orders ship on every dashboard load.
  • Writes are impossible by design — the server never writes back to server/data/.

Running it

Backend

cd server
uv run python main.py

Serves localhost:8001; interactive docs at /docs.

Frontend

cd client
npm install && npm run dev

Serves localhost:3000 with hot reload.

Tests

cd tests && uv run pytest backend/ -v

40 tests: 13 dashboard, 10 inventory, 17 across the remaining endpoints. They use FastAPI's TestClient, so no server needs to be running.
